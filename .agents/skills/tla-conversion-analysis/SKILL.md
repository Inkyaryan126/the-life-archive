# TLA Conversion Analysis

Use evidence rather than assumptions.

Analyze:
- visitors
- landing pages
- traffic sources
- person creation
- first memory
- additional memories
- contributor invitations
- contributor participation
- shares
- QR/NFC scans
- repeat visits
- keepsake checkout
- completed purchases

Break down meaningful differences by:
- campaign
- physical material
- device
- landing page
- new vs returning visitor
- relevant date range

Look for:
- largest funnel drop
- sudden changes
- high-performing acquisition sources
- high-performing user behaviors
- mobile/desktop gaps
- channels producing clicks but not activated users

Do not confuse correlation with causation.

End with:
1. biggest finding
2. likely explanation
3. highest-value next action
4. metric to watch
