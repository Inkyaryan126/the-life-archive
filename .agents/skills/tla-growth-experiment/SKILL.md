# TLA Growth Experiment

Optimize for meaningful growth, not vanity activity.

Primary funnel:
visitor
→ understands TLA
→ creates a person
→ adds first memory
→ shares/invites
→ family contributes
→ returns
→ buys or scans keepsake

For each experiment define:

## Problem
What measurable bottleneck exists?

## Hypothesis
Why should this change improve it?

## Change
What exactly should change?

## Primary Metric
One main success metric.

## Guardrail
What must not get worse?

## Audience
Who sees the experiment?

## Duration / Sample
Enough data to learn something useful.

## Decision
Ship, iterate, or kill.

Prefer experiments that improve:
- activation
- first-memory completion
- invitations
- contribution
- sharing
- repeat visits
- keepsake scans
- purchases
- partner acquisition

Avoid experiments that create complexity without a measurable learning goal.

Use actual TLA analytics when available.
