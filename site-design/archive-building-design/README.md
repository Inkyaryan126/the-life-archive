# Memory Cosmos Redesign Prompts

This workspace is a fresh prompt library for the premium Memory Cosmos direction for The Life Archive.

The direction is luxury, emotional, restrained, cinematic, and human. It is not science fiction, fantasy, AI collage, neon, gaming, or decorative space art.

## Product Personalities

The Life Archive should not use one visual personality everywhere.

### Public Site

Emotional, cinematic, premium. This is where the brand should stop people in their tracks and make them understand that a life can be preserved beautifully.

### Member Dashboard

Warm, personal, calming. It should feel like opening a treasured journal or walking into your life's library, not operating a satellite or managing a database.

Useful references:

- Apple Photos
- Notion
- Arc Browser
- Readwise
- Kindle Library

Avoid:

- Bloomberg Terminal
- Mission Control
- Grafana
- server dashboards
- giant charts
- analytics everywhere
- dense control panels

### Admin Dashboard

Practical, information-dense, and operational. This is where analytics, visitor data, fulfillment, and admin tools belong. The NASA/Mission Control influence only makes sense here in small doses, especially for analytics surfaces.

## Golden Rule

Before rendering, ask yourself:

Could this image appear on the homepage of Apple, Rolex, Bang & Olufsen, Leica, Aston Martin, or A24?

If the answer is no, redesign it before rendering.

Avoid every visual cliche associated with AI-generated artwork.

Prioritize restraint over spectacle.

Luxury over decoration.

Emotion over fantasy.

Silence over noise.

The image should make viewers stop scrolling, not because it is loud, but because it feels unlike anything else on the web.
