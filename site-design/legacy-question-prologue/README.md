# Legacy Question Prologue

This folder holds planning notes and source artwork for the isolated `/legacy-prologue` prototype.

The current Part One preview has four story scenes:

1. Funeral
2. Home
3. The Journey
4. At The Mansion

Part One ends at the closed-door threshold: the mourner grips the brass door handles, but the doors do not open.

Part Two begins later on the login screen. That sequence starts from the same threshold moment, lets the visitor intentionally choose to open the doors, and can then reveal memory fragments before the login form appears.

The active prototype route is intentionally isolated and is not connected to `/legacy-question`.

## Source-Master Order

The source-master folder is ordered by story mood, not by every camera angle becoming its own scene.

### Scene 1: Funeral

The opening can show the mansion or estate landscape from far back as part of the funeral world's emptiness. The progression should start with sadness and a sense of void, then introduce only a small glimmer of hope when the keychain is passed.
